
# Boy去插播 GO · 宝塔面板安装教程

全程在宝塔面板里点鼠标就能装好，不用敲命令。

---

## 一、先选对安装包

下载下来的压缩包有两个个，按你的服务器类型挑一个：

| 压缩包文件名 | 什么时候选 |
|---|---|
| `Boy去插播-1.3.2-linux-amd64.zip` | 绝大多数服务器选这个：阿里云、腾讯云、华为云的普通机型都用它 |
| `Boy去插播-1.3.2-linux-arm64.zip` | 只有“ARM 机型”选它：甲骨文 ARM、华为云鲲鹏、AWS Graviton 这类 |

> 拿不准就先装 amd64 那个。万一起不来，会提示 `cannot execute binary file`，再换 arm64 试一次就行。

包里面就两样东西：一个主程序 `Boyqcb`（没有后缀名），一个 `data` 文件夹（里面是已经配好的规则和记录）。解压出来直接用，不需要再装别的东西，也不需要装 Go 环境。

---

## 二、把压缩包传到服务器并解压

1. 打开宝塔面板，点左边菜单 **文件**。
2. 进入 `/www/wwwroot` 目录，点上方 **新建目录**，名字填 `boyqcb`，回车。
3. 进入刚建好的 `boyqcb` 目录，点上方 **上传**，把第一步选好的 zip 传上去。
4. 上传完，在文件列表里右键这个 zip → **解压**，解压到当前目录。
5. 解压后确认能看到 `Boyqcb` 这个文件。选中它 → 点上方 **权限**，数字填 `755`，勾上“应用到子目录/文件”，确定。

最终目录长这样：

```
/www/wwwroot/boyqcb/
├── Boyqcb          ← 主程序，权限必须是 755
├── data/           ← 已经配好的规则和记录，解压即可用
└── Linux部署说明.md
```

> `data` 文件夹里存着后台密码，别把这个目录发给别人。换到新服务器后，记得进后台把密码改掉。

---

## 三、用宝塔添加 Go 项目（核心步骤）

1. 宝塔左侧点 **网站**。
2. 上方切到 **Go 项目** 这一栏。
3. 如果提示“未安装 Go 项目管理器/环境”，按提示装一下（面板会自动装，等它装完）。
4. 点 **添加 Go 项目**，按下表填：

| 填什么 | 怎么填 |
|---|---|
| 项目目录 | `/www/wwwroot/boyqcb` |
| 执行文件 | `/www/wwwroot/boyqcb/Boyqcb` |
| 执行命令 | `/www/wwwroot/boyqcb/Boyqcb -addr :8091 -nobrowser` |
| 项目端口 | `8091`（要和上面执行命令里的数字一样） |
| 运行用户 | `root` |
| 开机启动 | 勾上 |

5. 点 **提交 / 保存**。
6. 回到 Go 项目列表，点这条项目右边的 **启动**。状态显示 **运行中**，就成功了。

> 想换端口？把“执行命令”里的 `:8091` 和“项目端口”一起改，两个数字必须一致，比如都改成 `:9000` 和 `9000`。

启动、停止、重启都在这一列右边的按钮上点；看报错点 **日志**。

---

## 四、把端口放行，不然外网打不开

两处都要放行，少一处就访问不了：

1. **宝塔里放行**：宝塔左侧 **安全** → 防火墙/系统防火墙 → 放行端口填 `8091`，备注随意，确定。
2. **云厂商后台放行**：去你买服务器那家（阿里云/腾讯云/华为云等）的控制台，找到这台机器的 **安全组 / 防火墙**，加一条规则：允许 TCP `8091`。

如果前面还套了 CDN（比如腾讯 EdgeOne），源站端口保持 `8091` 不变即可。

---

## 五、打开后台

浏览器访问：

```
http://你的服务器IP:8091/admin
```

- 默认账号：`admin`
- 默认密码：`admin123`

**进去第一件事：改密码。** 右上角或左侧 **系统设置** → 修改密码。（需要的话还能把后台地址 `/admin` 改成一个只有你知道的路径，改完会自动跳到新地址。）

---

## 六、装完顺手做的安全设置（建议做）

`data` 文件夹里是系统配置和密码，不能让别人下载。程序本身已经把它保护起来了，但如果你的站点是用 Nginx 承接的，建议在宝塔里再加一道：

1. 宝塔左侧 **网站** → 找到对应站点 → 点 **设置**。
2. 左侧点 **配置文件**（Nginx 配置）。
3. 在 `server {` 这一行的下面，另起一行粘进去：

```
location ^~ /data {
    return 404;
}
location ^~ /cache/ {
    autoindex off;
}
```

4. 点保存，然后重启一下 Nginx。

这样别人访问 `/data/...` 会看到“页面不存在”，跟访问一个乱敲的网址效果一模一样，不会暴露这个目录。

> 千万别写成 `deny all`，那会返回 403，等于告诉对方“这里有东西，只是不给你看”。要的就是装作不存在（404）。

---

## 七、想让接口只给自己用（可选）

后台 **系统设置** 里有 **IP 授权**：打开后，只有你填进去的 IP 才能调用解析接口、才能取缓存文件。

后台页面本身不受这个限制，任何 IP 都能打开登录页，再靠账号密码拦一道——这样不会把自己锁在门外。

---

## 八、出问题时这样查

| 现象 | 怎么处理 |
|---|---|
| Go 项目列表里状态起不来 | 点这条项目的 **日志**，里面写了具体原因 |
| 日志里写 `Permission denied` | 主程序没给执行权限，回第二步，把 `Boyqcb` 权限改成 `755` |
| 日志里写 `address already in use` | 8091 被别的东西占了，把端口换成 9000 之类的，两边都改 |
| 日志里写 `cannot execute binary file` | 包选错了，换另一个架构的 zip 重新解压 |
| 状态是运行中，但页面打不开 | 端口没放行：宝塔安全 + 云厂商安全组，两处都要放行（看第四步） |
| 页面能开，但解析报错 | 点 **日志** 看具体提示，多数是目标站点地址变了或需要代理 |

---

## 九、以后怎么升级

1. 在 Go 项目列表里点 **停止**。
2. 宝塔 **文件** 里进 `/www/wwwroot/boyqcb`，把新的 `Boyqcb` 传上去覆盖旧的（权限再确认一次是 755）。
3. 回 Go 项目列表点 **启动**。

`data` 文件夹不要动、不要删，规则、密码、记录全在里面。
